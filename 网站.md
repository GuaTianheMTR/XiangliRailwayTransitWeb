# 香力城市交通管理网站
## 1. 网站功能
1. 本网站为MTR服务器**香力**设计。
2. 网站顶端显示“香力城市交通管理网站”
3. 有多个页面，如下表：
   |  |首页|公司|成员|线路|聊天|管理员页面|
   |---|---|---|---|---|---|---|
   |功能|查看管理员上传的png路线图；查看香力城市简介；|管理员创建公司，并管理公司成员（来自成员页面）、所拥有线路（来自线路界面）|用户根据自己浏览器的数据创建并保存用户名，一个设备只可绑定一个用户成员（名字不可更改）|管理员添加线路，可编辑线路名称、类型（见后文）、颜色、编号|已注册（按用户名登录）的成员可以在此发送消息聊天，支持 Markdown/纯文本，并可上传（附加）网址 URL 与图片、Word、PDF、Excel、PPT 等文件（单个≤10MB）；可用 @ 提及成员或 @香力AI；消息存入数据库，所有用户可查看|用户进入此页面后，输入密码“xiangli9666”才可以进入，一个用户登陆成功一次管理员界面后，以后永远不需再次登录即可进入管理员界面。可以更改首页的线路图、简介，公司、成员、线路页面的所有信息以及内容。|
4. 有底部导航栏，可切换不同界面
5. 设计页面美观，新颖，适合轨道交通官方网站
6. 线路类型：
   - 轻轨
   - 高速列车
   - 城际列车
   - 市域快车
   - 地铁
   - 公交
   - 捷运
   - 普速列车
   - 轮渡
   （注： 每种类型的线路分类，在网页线路页面的线路表格排列在一起，按照名称、类型排序）
7. 管理员上传线路图、公司、线路等所有信息时，上传到一个数据库中（你自己写），让其他互联网用户也能读取
8. 一个成员名称即为一个账号，不同设备、浏览器登录一个名称即为同一账号
9. 成员等所有信息都要同步上传到数据库，另其他网络用户读取
10. 聊天功能：已注册（按用户名登录）的成员可在「聊天」页发送消息，支持 Markdown / 纯文本，并可上传（附加）网址 URL 及图片、Word、PDF、Excel、PPT 等文件（单个不超过 10MB）。消息保存到数据库，所有用户可查看，页面每 5 秒自动刷新；管理员可删除任意消息。
11. AI 助手：内置「香力AI」（默认智谱 GLM-4-Flash；管理员可在管理员页面调整模型、接口地址、温度、系统提示词，默认 API Key 存放在服务端，不在源码/客户端显示，保护密钥安全）。用户可在聊天中 @香力AI 向其提问香力相关信息、线路建设建议等；该 AI 熟悉 MTR 及香力所有相关信息，回复会自动出现在聊天中。
12. @ 提及：在聊天输入框输入 @ 可提及已注册成员或 @香力AI；被 @ 的成员会在网站顶部和底部导航「聊天」按钮显示小红点 / “有人@你哦” 标识，点击查看消息后消失。
13. 聊天输入：按 Enter 发送；按 Ctrl+Enter 或 Shift+Enter 换行。

# Xiangli City Traffic Management Website
## 1. Website features
1. This website is designed for the MTR server **Xiangli**. 
2. The website top displays "Xiangli City Traffic Management Website" 
3. There are multiple pages, as shown in the table below: 
| |Home|Company|Members|Line|Chat|Administrator Page|
|---|---|---|---|---|---|---|
|Features| View PNG route maps uploaded by administrators; View the introduction to Xiangli City; |Administrators create and manage company members (from member pages) and owned routes (from line interface) | Users create and save usernames based on their browser data; each device can only bind one user member (name cannot be changed) | Administrators add routes, edit line names, types (see below), color, and number | Registered members (logged in by username) can send messages here with Markdown/plain text and attachments (URLs, images, Word/PDF/Excel/PPT, max 10MB each); supports @ mentions of members and @香力AI; messages are stored in the database and visible to all users | After users enter this page, enter the password "xiangli9666" to enter. Once a user successfully logs into the administrator interface, they will never need to log in again to access the administrator interface. You can change the homepage route map, description, and all information and content of the company, members, and route pages. |
4. Includes a bottom navigation bar to switch between different interfaces
5. The design page is attractive, innovative, and suitable for the official rail transit website
6. Route Type: 
- Light rail
- High-speed trains
- Intercity trains
- Intercity Express
- Metro
- Public transport
- MRT
- Conventional trains
- Ferry
(Note: Each type of route is categorized in the route table on the webpage, sorted by name and type.)
7. When administrators upload all information such as route diagrams, companies, and lines, upload them to a database (you write them yourself), allowing other internet users to access them as well
8. One member name is one account; logging in with one name on different devices and browsers counts as the same account
9. All information including members must be synchronously uploaded to the database, and other network users can read it
10. Chat: registered members (logged in by username) can send messages on the Chat page with Markdown/plain text and attachments (URLs, images, Word/PDF/Excel/PPT, max 10MB each). Messages are saved to the database, visible to all users (auto-refreshes every 5 seconds); admins can delete any message.
11. AI assistant: a built-in "Xiangli AI" (defaults to Zhipu GLM-4-Flash; admins can adjust the model, API base URL, temperature and system prompt on the admin page; the default API key is stored server-side and never shown in source/client). Users can @香力AI to ask about Xiangli and route-planning suggestions; the AI knows MTR and all Xiangli-related info, and its reply appears automatically in the chat.
12. Mentions: type @ in the chat box to mention a registered member or @香力AI. Mentioned members see a red dot / "Someone mentioned you!" on the site top and the Chat nav button, which disappears after viewing.
13. Chat input: Enter to send; Ctrl+Enter or Shift+Enter for a new line.
